# JaalX Updates

This repository hosts published Windows releases and automatic-update files for JaalX — Supplier Price Comparison Desktop App.

Release assets are generated by the GitHub Actions workflow in the private `jaalx-source` repository.

## Downloads

Download the Windows installer from the [Releases page](https://github.com/Anjum440/jaalx-updates/releases).

## Automatic Updates

The NSIS-installed version of JaalX checks this repository for published updates. The portable edition requires manual updates.
